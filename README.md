# 🎓 Sistema de Gestión de Estudiantes

Aplicación de consola desarrollada con **Spring Boot** que permite gestionar estudiantes de forma simple: listar, buscar, agregar, modificar y eliminar.

---

## 🚀 Tecnologías utilizadas

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Lombok

---
